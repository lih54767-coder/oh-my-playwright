# Version history

## v1.0.0 (2026-05-20)

Initial release.

### Features
- Auto-detect login walls (7+ auth types: password, OAuth, SSO, MFA, QR code, CAPTCHA, SMS)
- One-time setup wizard (3 questions → final config → restart once)
- Multi-browser support (Edge, Chrome, built-in Chromium)
- Three connection modes (Extension, Persistent Profile, CDP)
- Authentication handling with manual login guidance
- Session state save/restore
- Anti-idle popup detection for automated scenarios
- Chinese language detection patterns (登录, 验证)
- Structured test case generation from exploration
